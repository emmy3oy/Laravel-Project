# Laravel Project

A Laravel web application built while learning PHP, Laravel, databases, authentication, CRUD operations, relationships, validation, and application structure.

The purpose of this project is not only to build an application, but also to understand how PHP concepts develop into a complete Laravel application.

---

## About This Project

This project started from learning the fundamentals of **PHP** and gradually moved into **Laravel**.

The development process was done step by step, starting with basic PHP concepts and eventually building features such as:

- User registration
- User login and authentication
- Protected routes
- Categories CRUD
- Database relationships
- Form validation
- Blade templates
- Laravel components
- Navigation
- Custom CSS
- MySQL database
- User-specific data
- Active/inactive status management

The project is also being used to understand how Laravel organizes a real web application using the MVC architecture.
